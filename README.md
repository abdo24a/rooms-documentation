# AI in the Modern SOC — Learning Notes

A personal learning summary created after completing the **AI in the Modern SOC** room on TryHackMe.

> This repository records general concepts and personal takeaways. It is **not** a room walkthrough, answer sheet, or reproduction of TryHackMe lab material.

## Learning focus

The room explores how AI can assist Security Operations Centre (SOC) work while keeping evidence validation and consequential decisions with the analyst. The practical learning context involved investigating an alert in Elastic Security, reviewing an AI-prepared case note against native event evidence, and recording an analyst-owned observation for handover.

## Main topics reviewed

- Where AI can support SOC workflows: detection engineering, alert triage, investigation and enrichment, response playbooks, and case documentation.
- The difference between detection analytics, deterministic automation, language-model output, AI-assisted workflows, and analyst decisions.
- The importance of checking generated summaries and claims against original security records.
- Data handling boundaries when using AI tools with security information.
- Human approval and authorised playbooks for response actions that affect systems or users.
- Clear case notes and useful handovers when an investigation still has open questions.

## Key takeaway

AI can help analysts organise information and prepare investigation drafts, but generated output is not verified evidence. The analyst must confirm important claims against the original records, identify uncertainty, and retain responsibility for the final assessment and authorised response.
